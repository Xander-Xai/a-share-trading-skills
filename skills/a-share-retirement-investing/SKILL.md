# A股长期养老选股与持仓 Skill

## 1. 目标

把“养老股”定义为一个长期股权现金流系统，而不是“高股息排行榜”。

本 Skill 优化以下目标：

1. **本金永久损失风险尽可能低**：优先选择商业模式耐久、资产负债表可承受压力、治理可靠的企业。
2. **分红可持续**：分红主要来自可重复的盈利和现金流，而非举债、资产处置或一次性收益。
3. **分红具备真实增长能力**：长期现金分红增速尽量覆盖通胀。
4. **买入估值合理**：好公司买得过贵，同样可能导致长期低回报。
5. **组合不过度集中**：不同股票必须提供不同的盈利驱动，不能“看似5只、实则押一个宏观变量”。
6. **保留成长引擎**：可使用 15%–25% 的权益仓位配置高质量科技/成长股，以改善长期资本增值能力。

> 本 Skill 管理的是“养老资产中的股票权益部分”。完整退休资产配置还应单独考虑现金、低波动资产、保险/社保、未来支出和流动性缓冲，不能把全部养老资金等同于股票账户。

## 2. 第一性原理

长期股东回报可近似拆为：

```text
长期总回报 ≈ 初始股息收益 + 每股盈利/每股分红可持续增长 + 估值变化
            - 税费 - 永久性资本损失
```

因此筛选顺序必须是：

```text
生存能力 → 盈利质量 → 现金流/资本约束 → 分红可持续性 → 增长 → 估值 → 当前股息率
```

**禁止反过来从“谁股息率最高”开始选。**

## 3. 强制实时数据协议

每次执行都必须先记录 `as_of` 日期，并联网获取最新信息。不得把本 Skill 中的历史价格、股息率或候选名单当作当前事实。

### 数据源优先级

1. 上交所 / 深交所 / 巨潮资讯 / 公司正式年报、半年报、季度报告、权益分派公告
2. 公司官网投资者关系与正式业绩说明材料
3. 证监会、财政部、税务总局、中证指数等监管/官方机构
4. 可靠行情服务商，仅用于价格、市值、估值等实时或近实时行情交叉验证
5. 主流财经媒体，只用于补充背景，不作为关键财务数字的唯一依据

### 每只股票至少验证

- 最新股价、总市值、总股本
- 最近 5–10 年现金分红记录；至少区分“普通分红”和“特别/一次性分红”
- 最近 3–5 年营收、归母净利润、扣非净利润、ROE/ROIC（按行业适配）
- 经营现金流、资本开支、自由现金流（银行等行业按行业适配指标替代）
- 资产负债、利息负担或监管资本
- 当前分红政策、股东回报规划、回购/增发/重大资本开支
- 当前 PE/PB/FCF Yield/股息率与自身历史估值分位（按行业选择）
- 审计意见、重大处罚、治理与关联交易异常

如果关键数据缺失或相互冲突，结论必须标记为 **“数据不足，暂不推荐”**，不得猜测。

## 4. 组合架构

默认将长期股票仓划分为两层：

### A. 核心现金流仓（Core Dividend）

- 默认占股票权益仓 **75%–85%**
- 目标：稳定盈利、可持续分红、较低永久损失概率、适度分红增长
- 不要求每只都达到最高股息率

### B. 成长卫星仓（Growth Satellite）

- 默认占股票权益仓 **15%–25%**
- 目标：提高组合长期资本增值能力
- 允许低股息甚至不以分红为主要目标
- 科技股必须单独使用成长评分体系，不得用“养老高股息评分”硬套

若用户给定额外硬条件，例如“股价 < 100 元、总市值 > 100 亿元”，将其作为 **本次筛选过滤器**；每次运行重新验证，不得永久写死。

## 5. 核心现金流仓：硬性排除项

任一项成立时，原则上排除或降为观察：

1. 未解决的重大审计、会计、治理或资金占用问题。
2. 连续多年主要依赖新增负债、出售资产或一次性收益维持高额分红。
3. 非金融企业的正常化盈利和正常化自由现金流长期无法覆盖分红，且没有合理的阶段性解释。
4. 银行等金融企业的分红明显侵蚀资本充足率或监管安全边际。
5. 商业模式存在明确、持续、不可逆的结构性衰退，而公司尚无可信的新增长来源。
6. 负债/利息负担在压力情景下不可承受。
7. 关键结论只能依赖传闻、预测或二手媒体，无法由正式披露验证。

## 6. 核心现金流仓：100分评分

| 维度 | 权重 | 核心问题 |
|---|---:|---|
| 商业耐久性与护城河 | 20 | 10–20年后需求是否仍存在？是否有成本、品牌、网络、牌照、资源或规模优势？ |
| 分红持续性与增长 | 20 | 是否连续分红？支付率是否合理？每股分红是否能随盈利增长？ |
| 盈利与现金流质量 | 15 | 利润能否转化为现金？是否依赖非经常损益？ |
| 资产负债表与生存能力 | 15 | 债务、利息、资本支出或监管资本是否稳健？ |
| 治理与股东回报纪律 | 10 | 分红/回购政策是否清晰、一致、可信？是否频繁损害中小股东？ |
| 估值与安全边际 | 15 | 当前价格相对正常化盈利、历史估值和合理价值是否有安全边际？ |
| 组合适配度 | 5 | 是否真正降低组合行业/因子集中度？ |

### 评分解释

- **80–100**：核心候选；仍需估值合格后分批建仓
- **70–79**：观察候选；等待价格或基本面改善
- **<70**：原则上不进入养老核心仓
- **任何硬性排除项优先于总分**

## 7. 成长卫星仓：100分评分

| 维度 | 权重 | 核心问题 |
|---|---:|---|
| 长期产业空间 | 20 | 是否处在 5–10 年仍可扩张的真实产业趋势，而非短期概念？ |
| 收入/利润增长质量 | 20 | 增长是否已经进入财务报表？扣非利润和现金流是否同步？ |
| 技术、产品与竞争壁垒 | 15 | 研发、客户粘性、平台/制造能力、产品迭代是否构成壁垒？ |
| 现金流与资产负债表 | 15 | 高增长是否依赖不可持续融资？ |
| 周期与客户集中风险 | 10 | 单一客户、单一资本开支周期、单一产品依赖有多大？ |
| 估值 | 15 | 当前估值需要怎样的未来增长才能兑现？是否隐含过度乐观假设？ |
| 组合适配度 | 5 | 是否提供与高股息核心仓不同的收益驱动？ |

成长股还必须做 **估值反推**：用当前市值/PE 反推市场隐含的 3–5 年利润增长要求，并判断该要求是否现实。

## 8. 行业适配

不同产业不能用同一套指标机械比较。执行时必须读取 `references/industry-checklists.md`。

尤其注意：

- 银行：不能用普通工业企业 FCF 逻辑；重点看资本充足率、不良率、拨备、净息差、ROE、分红率。
- 水电/公用事业：重点看来水/利用小时、资本开支、债务、运营现金流、资产寿命和电价机制。
- 电信：重点看经营现金流、资本开支强度、自由现金流、ARPU、云/算力增长、分红政策。
- 煤炭/石油：必须用中周期盈利，不能把商品价格高点利润外推到永续。
- 消费：重点看品牌、份额、现金转化、渠道库存、定价能力、ROIC/ROE。
- 科技/AI：重点看真实订单、收入、扣非利润、毛利率、研发、现金流、客户集中度与资本开支周期。

## 9. 估值与买入区间

不得使用“一刀切 PE 阈值”。至少交叉使用 2–3 种适合该行业的方法：

1. 当前股息率 vs 公司自身 5/10 年历史分位
2. PE/PB/EV-EBITDA/FCF Yield vs 自身历史与可比公司
3. 正常化 EPS × 合理估值倍数
4. 稳定现金流企业可做简化 DDM/DCF 作为 sanity check
5. 周期股使用中周期盈利，不使用景气高点 EPS
6. 银行优先结合 PB-ROE、资本质量和可持续分红

输出三个价格层级：

```text
Conservative Fair Value  保守合理价值
Base Fair Value          基准合理价值
Max Buy Price            最高愿意买入价（通常包含10%–20%安全边际）
```

不要因为“股息登记日临近”追涨。除息与现金分红属于总回报的一部分，不是无风险套利。

## 10. 建仓与仓位

默认原则：

- 单只股票初始目标仓位：股票权益仓的 **10%–20%**
- 单只股票上限：原则上 **25%**
- 单一行业/高度相关风险簇上限：原则上 **30%–35%**
- 成长卫星仓合计：原则上 **15%–25%**
- 煤炭、石油、火电等即使行业名称不同，也要按相关宏观/商品风险簇计算集中度

建仓采用 **3–5 批**：

1. 首批：估值达到可接受区间，建立观察性底仓
2. 后续加仓：估值更便宜且投资逻辑未破坏，或业绩继续验证逻辑
3. **禁止仅因为股价下跌机械补仓**
4. 基本面恶化时，即使价格更低也不得用“摊低成本”替代重新研究

## 11. 分红处理

### 积累阶段

优先将分红再投资，但不是机械买回原股票。每次分红资金进入“待配置现金池”，优先投向：

```text
仍通过硬性筛选 + 评分最高 + 当前估值最有安全边际
```

### 提取阶段

退休后可将分红作为现金流来源之一，但股票分红并非债券票息，不能假设永久固定。应在股票仓之外保留流动性缓冲，以避免市场大跌时被迫卖出股票满足生活开支。

个人股息红利税规则属于时效性政策，每次使用必须重新核验最新规定。

## 12. 持仓复核机制

### 季度轻复核

检查：

- 营收、归母/扣非利润是否偏离长期逻辑
- 经营现金流或行业替代指标
- 债务/资本充足情况
- 分红政策是否变化
- 关键经营 KPI
- 重大资本开支、并购、增发、监管变化

### 年度深复核

在审计年报后重做完整评分、正常化盈利、分红压力测试、估值和组合集中度。

### 事件驱动复核

以下事件立即触发：

- 减少/取消分红
- 重大收购或资产出售
- 大额增发/可转债/异常融资
- 审计意见变化、重大处罚、管理层治理问题
- 行业规则或价格机制重大改变
- 核心客户/核心产品发生结构性变化

## 13. 决策状态

每只股票只能给出以下五种状态之一：

- **ADD**：逻辑成立且估值具有足够安全边际，可分批增加
- **HOLD**：逻辑成立，但估值一般或仓位已合适
- **WATCH**：质量尚可但估值/数据/基本面存在待确认点
- **TRIM**：逻辑未破坏，但估值极端或仓位/行业集中度超限
- **EXIT**：投资逻辑发生结构性破坏

长期仓不设置机械短线止损。退出主要依据：

1. 结构性盈利能力受损
2. 分红削减反映基本面恶化，而非短期审慎资本安排
3. 债务/现金流/监管资本不可持续
4. 治理或会计红旗
5. 行业/商业模式发生永久性恶化
6. 极端高估且仓位过大，可先 TRIM；不能仅因“涨了很多”就卖出优质公司

## 14. 强制压力测试与对抗审查

最终推荐前必须回答：

1. **高股息陷阱**：股息高是因为现金流强，还是股价暴跌/利润即将下滑？
2. **周期高点陷阱**：当前盈利是否处于商品价格/行业景气高点？
3. **举债分红陷阱**：分红是否侵蚀偿债能力或未来增长？
4. **价值陷阱**：低 PE/PB 是否对应真实结构性衰退？
5. **相关性陷阱**：组合是否表面分散、实际押注同一利率/商品/地产/AI Capex？
6. **估值陷阱**：好公司是否已经把未来数年增长全部计价？
7. **预测幻觉**：哪些数字是已披露事实、哪些是市场一致预期、哪些是自己的估计？必须明确区分。
8. **反方论证**：为每只候选写出最强的 Bear Case，并给出可证伪/失效条件。

建议对非金融核心股至少测试：

```text
正常化利润 -20%
正常化利润 -30%
资本开支/利息支出上升
```

然后重新估算分红覆盖率和资产负债承受力。周期股需使用中周期利润。银行改用资本充足率、资产质量和盈利压力情景。

## 15. 输出合同

每次筛选最终至少输出一张表：

| 字段 | 要求 |
|---|---|
| 股票/代码 | 明确沪深市场代码 |
| 角色 | 核心现金流 / 成长卫星 |
| 评分 | 总分 + 关键分项 |
| 当前价格/市值 | 标注 as_of |
| 核心投资逻辑 | 3条以内 |
| 当前普通股息率 | 使用经确认的普通现金分红，不把特别股息误当常态 |
| 分红覆盖 | 正常化盈利/FCF或行业适配指标 |
| 分红趋势 | 5–10年趋势，标记削减年份 |
| 资产负债/资本质量 | 行业适配 |
| 估值 | 当前值 + 历史/行业参照 |
| 合理价值区间 | Bear/Base/Bull 或 Conservative/Base/Max Buy |
| 建议状态 | ADD/HOLD/WATCH/TRIM/EXIT |
| 最大仓位 | 单股与行业风险簇限制 |
| Bear Case | 最强反方理由 |
| 失效条件 | 可量化或可观察 |
| 证据 | 优先官方链接，标注报告期 |

组合层面必须额外输出：

- 核心仓/成长仓比例
- 行业与风险簇集中度
- 组合预期普通股息率（只作情景估计，不作保证）
- 未来12个月应重点复核的事件
- 与上一轮结论相比发生了什么变化

## 18. 证据基线

本 Skill 的核心原则参考并验证于：

- 中国证监会《上市公司监管指引第3号——上市公司现金分红（2023年修订）》：强调稳定分红，同时要求兼顾盈利、资金支出、债务偿还能力，并关注高负债/弱经营现金流下的异常高比例分红。
  https://www.csrc.gov.cn/csrc/c100028/c7449654/content.shtml
- 中证红利指数编制方案：要求过去三年连续现金分红，且股利支付率处于合理区间。
  https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/20231208175433-000922_Index_Methodology_cn.pdf
- 中证红利质量指数：在连续分红基础上进一步强调股利支付率和盈利能力。
  https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/20231208180546-931468_Index_Methodology_cn.pdf
- 财税〔2015〕101号：个人持有沪深上市公司股票超过1年的股息红利所得暂免个人所得税；1个月以内和1个月至1年的实际税负规则需按最新政策复核。
  https://fgk.chinatax.gov.cn/zcfgk/c102416/c5203902/content.html

**原则：先保证公司能长期活、长期赚、长期产生现金，再讨论分多少；先判断价格是否值得，再决定买多少。**
