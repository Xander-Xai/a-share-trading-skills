# A股长期养老选股方法论 v1.0

> 目标：把“长期吃股息”从一个选股偏好，升级为可复用、可验证、可迭代的长期权益管理系统。

## 一、先定义问题：我们到底在优化什么

养老型股票投资的目标不是“今年拿最多股息”，而是未来多年持续获得**可购买真实商品与服务的现金流**，同时尽量避免本金永久损失。

因此需要同时处理五类风险：

1. **企业风险**：公司未来还能不能持续赚钱。
2. **分红风险**：利润存在，但是否能以现金形式长期回到股东手里。
3. **通胀风险**：每股分红若长期不增长，真实购买力会下降。
4. **估值风险**：优质公司买得过贵，也可能长期回报不佳。
5. **组合风险**：几只股票可能看似分散，实则都依赖同一宏观变量。

由此得到一个关键结论：

```text
高股息 ≠ 高质量养老资产
```

高股息可能来自：

- 优质现金牛，股价合理；
- 周期高点的高利润；
- 股价因为基本面恶化而暴跌；
- 特别分红/资产处置；
- 公司以高支付率甚至举债维持分红。

只有第一类最接近我们真正需要的资产。

## 二、回报拆解

对长期持有者，可以用以下框架思考：

```text
长期年化股东回报
≈ 起始普通股息率
+ 每股正常化盈利/分红增长
+ 估值均值回归或扩张
- 税费
- 永久性资本损失
```

其中：

- **起始股息率** 提供当前现金回报；
- **分红增长** 决定未来现金流能否抗通胀；
- **估值变化** 影响买入后资本回报，但长期不可依赖 PE 无限扩张；
- **永久性资本损失** 是养老账户最需要避免的尾部风险。

所以 Skill 的真正优化函数是：

```text
最大化：可持续的长期真实现金流 + 合理资本增值
约束：永久损失概率、行业集中度、估值过高、分红不可持续
```

## 三、为什么必须把“核心分红仓”和“成长仓”拆开

纯高股息组合容易集中于银行、煤炭、石油、电信、公用事业等成熟行业。这些资产现金流较好，但长期增长速度可能不足。

纯成长组合又可能面临：

- 估值高；
- 现金流弱；
- 产业迭代快；
- 龙头更替频繁；
- 股价波动大。

因此更合理的结构是：

```text
Core Dividend 75%–85%
+ Growth Satellite 15%–25%
```

核心仓负责：

- 稳定股东现金流
- 降低组合波动和永久损失概率
- 提供可复投现金

成长仓负责：

- 提供长期盈利增速
- 对抗成熟行业增长放缓
- 增强组合的资本增值潜力

这两个仓位必须使用不同评分体系。

## 四、核心分红股的筛选漏斗

### Level 0：数据可信性

先确认：

- 股票代码与公司主体无误；
- 最新年报/半年报可获取；
- 分红数据来自正式公告；
- 当前价格和市值有最新行情；
- 特别股息没有误记为普通股息。

无法验证就停止。

### Level 1：企业是否具有长期存在价值

问五个问题：

1. 10–20年后这个产品/服务还会有人需要吗？
2. 公司是否拥有资源、牌照、品牌、网络、成本、技术、规模或客户关系壁垒？
3. 行业是否需要持续高额资本投入才能维持现状？
4. 公司是否长期有能力赚取高于资本成本的回报？
5. 外部监管、技术替代、人口结构是否可能破坏商业模式？

### Level 2：利润是否是真利润

重点排查：

- 扣非利润与归母利润差异；
- 应收账款增长是否明显快于收入；
- 存货是否异常；
- 经营现金流与利润长期背离；
- 大量资本化支出是否美化利润；
- 一次性资产出售/公允价值变动是否支撑利润。

### Level 3：分红是否可持续

至少分析：

```text
普通现金分红 / 正常化归母净利润
普通现金分红 / 正常化自由现金流
过去5–10年每股分红轨迹
削减分红的年份及原因
```

注意：

- 支付率越高不一定越好；
- 低资本开支成熟公司可以有较高支付率；
- 高资本开支或成长阶段企业需要保留更多现金；
- 银行使用资本充足率和监管资本约束替代普通 FCF 分析。

### Level 4：资产负债表能否穿越压力

养老股的核心不是“平时很稳”，而是**坏年份也不用通过伤害股东来活下去**。

至少检查：

- 净负债/EBITDA（适用时）
- 利息覆盖倍数
- 债务期限结构
- 未来资本开支
- 有息负债成本
- 信用评级变化
- 银行资本充足率与核心一级资本

### Level 5：价格是否合适

不能把“公司好”和“现在值得买”混在一起。

每只股票必须分别判断：

```text
Quality：这是不是长期好资产？
Price：当前价格有没有足够未来回报？
Portfolio Fit：放进当前组合是否真正分散？
```

三个答案都合格才进入 ADD。

## 五、分红质量的六个层次

从低到高：

1. **偶发分红**：没有稳定历史。
2. **高股息但波动大**：周期高点分红显著增加。
3. **稳定金额分红**：每股金额稳定，但增长有限。
4. **稳定比例分红**：与盈利同步，但利润可能周期波动。
5. **稳定且增长的分红**：每股分红长期上升，现金流可覆盖。
6. **稳定增长 + 良好资本配置**：公司同时能分红、回购、再投资，并维持高资本回报。

养老核心优先寻找 4–6 层。

## 六、特别股息必须剔除出“常态股息率”

计算长期股息率时必须拆分：

```text
Ordinary Dividend Yield = 普通现金分红 / 当前股价
Special Dividend Yield  = 特别分红 / 当前股价
```

特别分红只能作为额外回报，不得直接外推到未来。

否则会产生典型高股息陷阱。

## 七、分红压力测试

### 非金融公司

至少做三个情景：

| 情景 | 正常化利润 | 现金流/资本开支假设 | 观察 |
|---|---:|---|---|
| Base | 100% | 正常 | 当前分红覆盖 |
| Stress 1 | 80% | Capex +10% 或利息上升 | 分红能否维持 |
| Stress 2 | 70% | Capex +20% 或现金转化下降 | 是否必须削减分红/加杠杆 |

要计算：

- 分红支付率
- FCF 覆盖倍数
- 净债务变化
- 利息覆盖变化

### 银行

改为测试：

- 净息差下降
- 信用成本上升
- ROE下降
- 不良率上升
- CET1/核心一级资本缓冲下降

判断在压力情景下是否仍有能力保持合理分红而不损伤监管资本。

### 周期资源股

必须先把利润调整到中周期：

```text
正常化利润 = 基于中周期商品价格、正常销量、正常成本计算
```

禁止直接用煤价、油价、金属价格高点盈利计算“可持续股息率”。

## 八、估值框架

### 1. 历史股息率分位

比较当前普通股息率与公司自身 5–10 年历史区间。

若当前股息率异常高，需要首先判断：

- 价格是否因为基本面恶化下跌？
- 去年分红是否包含特别分红？
- 下一年盈利是否可能下降？

### 2. 正常化 PE

```text
Normalized PE = 当前市值 / 正常化利润
```

周期股尤其重要。

### 3. PB-ROE

适合银行等资产负债表驱动企业。

低 PB 只有在 ROE 可持续时才具有意义。

### 4. FCF Yield

```text
FCF Yield = 正常化自由现金流 / 企业或股权价值（按口径保持一致）
```

适合成熟非金融现金牛。

### 5. DDM/DCF sanity check

不追求小数点精确，而是测试当前价格隐含的增长假设是否合理。

### 6. 安全边际

输出：

- Conservative Fair Value
- Base Fair Value
- Max Buy Price

通常 Max Buy Price 低于 Base Fair Value 10%–20%；极度稳定企业可略低，周期/科技企业应更高。

## 九、科技成长卫星仓的第一性原理

成长股不是“概念最热”，而是：

```text
产业需求增长
→ 公司获取订单/份额
→ 收入增长
→ 利润增长
→ 现金流改善
→ 每股价值增长
```

如果链条停在“产业很热”而没有进入财务报表，只能算主题投资，不适合作为养老账户的成长卫星核心。

### 必查问题

1. 过去 2–3 年增长来自量、价、并购还是一次性订单？
2. 扣非利润是否跟上收入？
3. 经营现金流是否跟上利润？
4. 毛利率/净利率是否因竞争持续下降？
5. 前五大客户集中度是否过高？
6. 当前估值隐含怎样的 3–5 年增长？
7. AI/半导体/云计算等需求是否过度依赖大客户 Capex？
8. 如果行业增速从 50% 降到 20%，当前估值还能成立吗？

### 用户硬过滤器

例如：

```text
股价 < 100元
总市值 > 100亿元
```

只用于本次候选筛选，不代表价值判断。股票拆分、价格上涨、市值变化都可能使条件失效，因此必须实时验证。

## 十、组合风险不能只按“行业名称”看

应建立风险簇：

| 风险簇 | 可能包含 |
|---|---|
| 能源商品 | 煤炭、石油、部分火电 |
| 利率/信用 | 银行、保险、地产链 |
| 公用事业 | 水电、核电、电网相关 |
| 消费需求 | 食品饮料、家电、零售 |
| AI Capex | AI服务器、数据中心、光通信、部分芯片 |
| 出口/海外客户 | 消费电子、制造链 |

两只股票即使申万行业不同，只要盈利驱动高度相同，也应合并计算集中度。

## 十一、建仓逻辑

### 为什么分批

分批不是为了“确保买到最低价”，而是为了管理两个不确定性：

- 估值判断误差
- 基本面信息逐步释放

建议 3–5 批：

```text
第1批：估值进入可接受范围
第2批：价格更有安全边际且逻辑未变
第3批：财报/经营数据继续验证
第4/5批：极端市场错杀或明确价值提升
```

**禁止自动补仓。**

股价下跌必须先回答：

```text
这是价格波动，还是价值下降？
```

## 十二、持仓不是“永不卖”

长期持有应理解为：

> 在投资逻辑持续成立时，尽量减少无意义交易。

而不是：

> 买入后无论发生什么都不卖。

### EXIT：逻辑破坏

- 盈利能力结构性下降
- 分红被迫削减且原因是现金流/偿债恶化
- 治理/会计问题
- 资产负债表失控
- 商业模式被永久替代

### TRIM：逻辑仍成立但风险失衡

- 估值进入极端乐观区间
- 单股仓位被上涨推到上限以上
- 同风险簇过度集中

### HOLD：逻辑成立、价格一般

不因为短期涨跌做动作。

### ADD：逻辑成立 + 估值有明显安全边际

分批加仓，而非一次满仓。

## 十三、分红复投策略

积累期最优先的问题不是“收到多少现金”，而是：

```text
这笔现金现在投向哪里能获得最高的风险调整后长期回报？
```

所以使用“组合级复投”：

1. 分红进入现金池；
2. 对现有持仓和候选池重新评分；
3. 只给仍通过硬性筛选的公司加仓；
4. 优先买估值最有安全边际、组合适配度最高的股票；
5. 如果没有合格标的，可以持有现金等待，不强制复投。

退休提取期则应把“生活支出现金缓冲”与股票组合分开，降低熊市被迫卖股风险。

## 十四、复核节奏

### 每季度：10–20分钟/公司轻复核

只回答：

- 逻辑有没有变？
- 现金流/资本质量有没有明显恶化？
- 管理层有没有改变资本配置？
- 是否触发失效条件？

### 每年：年报深复核

重做：

- 全部评分
- 5–10年分红轨迹
- 正常化利润
- 压力测试
- 合理价值
- 行业与风险簇集中度

### 事件发生时：立即复核

不等季度。

## 十五、对抗审查清单

每次推荐前必须由“反方”尝试推翻结论：

### A. Yield Trap Test

“如果明年利润下降30%，当前高股息还能存在吗？”

### B. Peak Cycle Test

“当前是不是行业盈利最好的一年？”

### C. Debt-funded Dividend Test

“分红之后净负债是否持续恶化？”

### D. Governance Test

“控股股东、关联交易、并购、增发是否可能把价值从中小股东转移出去？”

### E. Correlation Test

“删掉股票名称，只看利润驱动，这5只真的不同吗？”

### F. Valuation Reverse DCF Test

“当前股价要求未来增长多少年、多少比例才能合理？”

### G. Replacement Test

“如果今天一股都没持有，我还会以当前价格买它吗？”

### H. Opportunity Cost Test

“同样风险下是否存在明显更高质量、更便宜的替代品？”

只有通过这些问题后，才能给 ADD。

## 十七、监管与指数方法对本框架的验证

本方法没有把“高股息”单独作为最高优先级，原因与官方监管逻辑一致：证监会 2023 年现金分红规则在鼓励稳定分红的同时，明确要求综合考虑盈利水平、资金支出和偿债能力，并对高负债、经营现金流较弱却高比例分红的公司保持关注。

中证红利指数也不是只按单年股息率排序，而是要求过去三年连续现金分红、支付率处于正且合理区间；中证红利质量指数进一步把盈利能力纳入选样。

因此我们的框架比“股息率排行榜”多了三层：

```text
分红连续性
+ 分红覆盖能力
+ 盈利质量/资产负债安全
```

这三层是长期养老股票体系的核心。
