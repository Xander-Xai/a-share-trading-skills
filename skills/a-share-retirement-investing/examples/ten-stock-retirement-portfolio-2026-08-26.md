## 2. 结构判断

```text

```

- 水电 / 公用事业；

- 食品消费；

```text

```

正式行业不同不代表经济风险独立，实际仓位继续受 shared policy 风险簇上限约束。

## 4. 单股市场验证快照

### 4.1 长江电力 — Core 一级

2025 年普通现金分红合计约 1.00 元/股；按 28.24 元快照价，对应历史股息率约 3.54%。

2026Q1 收入和利润仍保持增长，经营现金流未出现结构性恶化信号。

```text
质量：高
分红：稳定
现金流：强
增长：中低速
主要风险：来水、电价机制、Capex、并购/杠杆、估值
状态：Core 一级，真实买入仍需估值 Gate
```

### 4.2 招商银行 — Core 一级

2025 全年现金分红约 2.016 元/股；按 39.80 元快照价，对应历史股息率约 5.07%。

2026Q1 资产质量总体稳定，但净息差继续承压。

```text
质量：高
分红：较强
优势：零售/财富管理、资产质量、资本能力
主要风险：NIM、宏观信用、地产/地方信用暴露、监管资本
状态：Core 一级
```

### 4.3 伊利股份 — Core 一级

2025 中期 + 年度普通现金分红合计约 1.38 元/股；按 26.10 元快照价，历史股息率约 5.29%。

2026Q1 营收、归母、扣非增长，经营现金流改善。

```text
质量：高
分红：较强
现金流：改善
主要风险：消费需求、原奶周期、渠道库存、竞争
状态：Core 一级
```

### 4.4 中国石油 — Core 二级 / 周期

2025 全年普通现金分红约 0.47 元/股；按 11.01 元快照价，历史股息率约 4.27%。

2026Q1 在油价承压环境下仍表现出一定盈利韧性。

```text
质量：较高
属性：强周期
核心要求：使用中周期油价/正常化盈利
主要风险：油价、天然气价格、Capex、政策
状态：保留，受能源风险簇限制
```

### 4.5 中国电信 — Core 二级 / WATCH

2025 普通现金分红约 0.272 元/股；按 6.42 元快照价，历史股息率约 4.24%。

截至本快照时点，2026H1 已公开。公开数据相比 2025H1 显示：

- 营业收入约 2590.10 亿元，同比下降约 3.9%；
- 归母净利润约 195.88 亿元，同比下降约 14.9%；
- 扣非归母净利润约 174.90 亿元，同比下降约 19.5%。

因此不能继续用 Q1 作为“最新经营验证”。

```text
分红：仍具有长期研究价值
当前问题：H1 收入和利润明显承压
需要验证：ARPU、产业数字化/云算力利润质量、Capex、现金流
状态：WATCH / HOLD 候选；新买入必须重新评分和估值
```

### 4.6 格力电器 — Core 二级 / WATCH

2025 普通现金分红约 3.00 元/股；按 41.58 元快照价，历史股息率约 7.21%。

2026H1 报告在本快照时间之前已经公开，数据显示：

- 营收约 893.98 亿元，同比 -8.15%；
- 归母净利润约 132.78 亿元，同比 -7.87%；
- 扣非归母净利润约 127.07 亿元，同比 -8.89%；
- 经营现金流约 188.09 亿元，同比约 -33.6%。

这意味着不能再把“高股息 + Q1小幅增长”作为当前主要论据。

```text
历史股息率：高
当前经营：H1 明显走弱
核心风险：需求、渠道、增长、现金流、资本配置
状态：WATCH；保留研究资格，但新买入要求更高安全边际
```

高股息不构成自动 ADD。

### 4.7 中国神华 — Core 二级 / 周期

2025 中期 + 年度分红合计约 2.01 元/股；按 47.26 元快照价，历史股息率约 4.25%。

2026Q1 利润同比承压，因此必须用中周期煤价和正常化盈利评估长期分红。

```text
分红：较强
优势：煤电运一体化
主要风险：煤价、长协机制、周期盈利回落
状态：保留，不因历史分红机械加仓
```

### 4.8 工业富联 — Growth 主仓

2026H1 收入、归母、扣非与经营现金流均实现强劲增长，AI服务器/算力基础设施需求已经进入财务报表。

```text
产业空间：高
增长质量：当前三只 Growth 中最好
主要风险：AI Capex、客户集中、供应链/地缘、制造利润率、估值
状态：Growth 第一研究优先级
```

### 4.9 立讯精密 — Growth 副仓

2026H1 收入增长较快，汽车电子和通信/数据中心业务扩张明显，但扣非利润增速明显低于收入增速；经营现金流也需要持续验证。

```text
优势：消费电子 + 汽车 + 数据中心多引擎
问题：利润率、扣非质量、现金流
主要风险：大客户集中、消费电子周期、并购整合
状态：Growth 第二研究优先级
```

### 4.10 中科曙光 — Growth 高弹性小仓

2026H1 收入、归母和扣非保持较高增长，经营现金流同比改善，但快照估值在三只 Growth 中最高。

```text
业务：通过
增长：通过
核心风险：估值
其他风险：订单周期、国产算力节奏、技术迭代
状态：Growth 小仓，买入要求更高安全边际
```

## 6. 真实购入前的建仓规则

禁止看到本文件后按快照价一次性买满。

每只股票真实执行前必须重新计算：

- current price；
- Conservative Fair Value；
- Base Fair Value；
- Max Buy Price；
- 当前评分；
- 当前单股/风险簇上限；
- 最新财报/分红/治理事件；
- 当前 policy / skill version。

策略批次以 shared policy 为准：

```text
默认：40% / 30% / 30%
2批例外：60% / 40%
4批例外：30% / 25% / 25% / 20%
```

第2/3/4批都必须有新的价格或事实确认，不能因为价格下跌机械补仓。

对中科曙光等估值/波动更高的标的，四批模式可作为保守候选，但仍需当时重新判断，不能永久写死。

## 7. 补仓、止损、止盈

### 补仓

只有以下全部通过才允许长期 ADD：

```text
Thesis Gate
Balance Gate
Valuation Gate
Portfolio Gate
```

### 止损

长期仓不使用统一 -5%/-8%/-10% 自动止损。结构性 thesis 破坏、盈利能力永久恶化、现金流/资本失控、治理红旗等才进入 EXIT 逻辑。

### 止盈

不按固定盈利百分比全部卖出。主要用：

```text
估值
+ 单股/风险簇集中度
+ 机会成本
+ thesis 状态
```

决定 HOLD / TRIM / EXIT。
