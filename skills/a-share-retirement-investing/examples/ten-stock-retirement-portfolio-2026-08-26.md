## 2. 组合结构判断

这十只作为“研究候选仓库”通过长期 Skill 的结构性检查：

```text
7 只 Core Dividend
+
3 只 Growth Satellite
```

主要经济驱动覆盖：

- 水电/公用事业；
- 银行利率与信用；
- 食品消费；
- 家电消费；
- 石油；
- 煤炭；
- 通信运营；
- AI服务器/算力基础设施；
- 消费电子/汽车电子/数据中心；
- 国产算力。

但“行业不同”不等于完全分散，至少有两个明显风险簇：

```text
能源商品簇：
中国石油 + 中国神华

AI / 科技资本开支簇：
工业富联 + 立讯精密 + 中科曙光
```

实际仓位必须继续受 shared policy 的风险簇上限约束。

结构：


符合长期 Skill 当前 `Core 75%–85% / Growth 15%–25%` 的内部结构。

### 注意

以上权重是“模型组合基线”，不是所有资金规模下的强制实盘权重。

真实下单时必须先读取 shared policy：

- 资金较小时，10 只同时实盘可能受 100 股交易单位和分散效率限制；
- 资金增大后，单股目标上限会下降；
- `live_target_weight = min(model_weight, 当前 shared-policy 单股上限)`；
- 若单一风险簇超限，优先降低相关股票实际权重，而不是为了保持模型比例违反上位规则。

## 4. 单股市场验证快照

### 4.1 长江电力 — Core 一级

2025 年普通现金分红合计约 1.00 元/股；按快照价 28.24 元，对应历史股息率约 3.54%。

2026Q1 公开数据：收入与利润仍保持增长，经营现金流没有出现结构性恶化信号。

判断：

```text
质量：高
分红：稳定
现金流：强
增长：中低速
主要风险：来水、电价机制、资本开支、估值过高
状态：核心保留
```

### 4.2 招商银行 — Core 一级

2025 全年现金分红约 2.016 元/股；按快照价 39.80 元，对应历史股息率约 5.07%。

2026Q1 资产质量总体稳定，但净息差继续承压。

判断：

```text
质量：高
分红：较强
主要优势：零售银行、资产质量、资本能力
主要风险：息差、宏观信用周期、监管资本
状态：核心保留
```

### 4.3 伊利股份 — Core 一级

2025 中期 + 年度普通现金分红合计约 1.38 元/股；按 26.10 元快照价，历史股息率约 5.29%。

2026Q1 营收、归母、扣非增长，经营现金流改善。

判断：

```text
质量：高
分红：较强
现金流：改善
主要风险：消费需求、原奶周期、渠道库存、竞争
状态：核心保留
```

### 4.4 中国石油 — Core 二级 / 周期

2025 全年普通现金分红约 0.47 元/股；按 11.01 元快照价，历史股息率约 4.27%。

2026Q1 在油价同比承压环境下仍保持一定盈利韧性。

判断：

```text
质量：较高
现金流：强周期属性
核心要求：使用中周期油价/盈利，不得外推景气高点
主要风险：油价、天然气价格、资本开支、政策
状态：保留，受能源风险簇约束
```

### 4.5 中国电信 — Core 二级 / WATCH

2025 普通现金分红约 0.272 元/股；按 6.42 元快照价，历史股息率约 4.24%。

2026Q1 营收、归母和扣非同比下降，但经营现金流明显改善。

判断：

```text
分红政策：仍具吸引力
当前问题：盈利端出现阶段性压力
正向观察：经营现金流改善
主要风险：ARPU、资本开支、云/算力盈利质量、竞争
状态：HOLD / WATCH，等待后续财报验证
```

### 4.6 格力电器 — Core 二级 / 高分红

2025 普通现金分红约 3.00 元/股；按 41.58 元快照价，历史股息率约 7.21%。

2026Q1 归母利润小幅增长，但扣非和经营现金流表现需要继续跟踪。

判断：

```text
股息率：高
风险：不能因为高股息率直接成为最大仓位
主要风险：空调需求、渠道、现金流、增长空间
状态：保留，限制集中度
```

### 4.7 中国神华 — Core 二级 / 周期

2025 中期 + 年度分红合计约 2.01 元/股；按 47.26 元快照价，历史股息率约 4.25%。

2026Q1 利润同比承压，因此必须使用中周期煤价和正常化盈利评估长期分红。

判断：

```text
分红：较强
产业链：煤电运一体化提供韧性
主要风险：煤价、长协机制、周期盈利回落
状态：保留，不因历史高分红机械加仓
```

### 4.8 工业富联 — Growth 主仓

2026H1 公开数据体现收入、归母、扣非与经营现金流的强劲增长，AI服务器/算力基础设施需求已经进入财务报表。

判断：

```text
产业空间：高
增长质量：当前三只 Growth 中最好
估值：需要持续和增长兑现速度匹配
主要风险：AI Capex、客户集中、供应链/地缘、制造业利润率
状态：Growth 第一优先
```

### 4.9 立讯精密 — Growth 副仓

2026H1 收入增长较快，汽车电子和通信/数据中心业务扩张明显，但扣非利润增速低于收入增速。

判断：

```text
优势：消费电子 + 汽车 + 数据中心多引擎
问题：需要继续验证利润率和现金流质量
主要风险：大客户集中、消费电子周期、并购整合
状态：Growth 第二优先
```

### 4.10 中科曙光 — Growth 高弹性小仓

2026H1 收入、归母和扣非保持较高增长，经营现金流同比改善，但快照估值在三只 Growth 中最高。

判断：

```text
业务：通过
增长：通过
核心风险：估值
主要风险：订单周期、国产算力投资节奏、估值压缩
状态：Growth 小仓，买入必须要求更高安全边际
```

## 6. 真实购入前的建仓规则

禁止看到本文件后直接按快照价格一次性买满。

每只股票真实执行前必须重新计算：

- 当前价格；
- Conservative Fair Value；
- Base Fair Value；
- Max Buy Price；
- 当前模型评分；
- 当前单股/风险簇上限；
- 最新财报/分红/治理事件。

### 默认策略批次

```text
40% / 30% / 30%
```

触发：

1. 第一批：质量、估值、组合适配通过，价格处于可接受买入区间；
2. 第二批：更高安全边际，或新财报/经营事实继续验证原逻辑；
3. 第三批：强确认，且单股/风险簇仍未超限。

### 更高不确定性股票

对估值较高、波动较大或单股目标金额较大的标的，可使用：

```text
30% / 25% / 25% / 20%
```

本组合中，中科曙光应优先考虑更保守的四批模式；其他 Growth 也可在估值或波动明显升高时切换四批。

### 明确禁止

```text
跌了
→ 自动补仓
```

长期后续加仓必须同时通过：

```text
Thesis Gate
Balance Gate
Valuation Gate
Portfolio Gate
```

## 7. 持仓管理

每只股票始终保持一个状态：

```text
ADD / HOLD / WATCH / TRIM / EXIT
```

### 复核频率

- 季度：轻复核；
- 年报：完整重做评分、正常化盈利、压力测试和估值；
- 重大事件：立即复核。

### 下跌处理

```text
约 -15%～-20%
→ 强制重新研究

约 -25%～-30%
→ 深度 thesis review
```

这些是研究触发器，不是自动补仓/止损线。

### 止损

长期仓默认使用投资逻辑止损：

- 商业模式/护城河结构性破坏；
- 正常化盈利能力永久下降；
- 分红削减且背后是现金流、偿债或资本恶化；
- 重大审计、造假、治理问题；
- 债务或资本结构明显失控；
- 原始 thesis 被事实证伪。

### 止盈

不使用“盈利达到固定百分比就清仓”。

主要通过：

```text
估值过高
+ 单股/风险簇超配
+ 机会成本
+ 基本面变化
```

决定 `TRIM / EXIT`。

## 8. 分红处理

积累期：

```text
现金分红
→ 进入组合级待配置现金池
→ 重新比较十只现有持仓 + 新候选
→ 投给仍通过硬筛选且安全边际更高的标的
```

不机械把分红买回原股票。

```yaml

```

组合层面至少计算：

- NAV 总收益；
- 股价收益；
- 现金分红收益；
- Core / Growth 收益贡献；

- 换手率；

- 相对基准表现。

建议同时保留一个宽基全收益基准和一个红利/价值类全收益基准，避免只看绝对赚钱而无法判断策略是否创造额外价值。

## 10. 本示例的目的

不是证明这十只一定长期赚钱，而是建立一条可被证伪、可迭代的研究记录：

```text
2026-08-26 初始研究
→ 模拟持仓
→ 定期财报/分红复核
→ 记录实际收益与回撤
→ 检查错误来自选股、估值、建仓还是持仓管理
→ 用真实数据更新长期 Skill
```

这使长期养老 Skill 从“方法论文件”变成可以持续做 forward test 的投资系统。
