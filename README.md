### 股票专用资金默认基线

| 股票资金规模 | 长期养老仓 | 短中期仓 |
|---:|---:|---:|
| ≤5 万 | 70% | 30% |
| 5–30 万 | 75% | 25% |
| 30–200 万 | 80% | 20% |
| 200–1000 万 | 85% | 15% |
| ≥1000 万 | 85%–90% | 10%–15% |

这张表只是 Size Cap。最终短中期仓位还必须满足：

```text
Short Allocation
= min(Size Cap, Risk Cap, Edge Cap)
```

也就是说，交易系统没有经过充分验证，或短中期压力回撤对总账户造成的潜在损失过高时，实际短中期仓位应低于表格值。

## 建仓基线

```text
长期单股：默认 3 批 40/30/30
必要时：2 批 60/40 或 4 批 30/25/25/20

短中期单股：默认 2 批 50/50
第三批只允许正向确认式 50/30/20
```

A股 100 股交易单位、小资金账户、估值变化、单股流动性和交易信号失效可以触发降批次或拆单；分批次数不得凌驾于目标仓位和风险预算之上。

## 共享风险规则摘要

```text
长期：
- 下跌不是自动补仓信号
- 默认不设机械百分比止损
- 用投资逻辑、财务质量、估值和集中度决定 ADD/HOLD/TRIM/EXIT
- 大资金提高持股数量，单股上限逐步下降

短中期：
- 单笔最大风险默认 ≤ 短中期仓净值 1%
- 全部未平仓初始风险合计 ≤ 3%
- 禁止向亏损仓位补仓摊成本
- 入场前先定失效点，再反推仓位
- 优先选择潜在收益/风险 ≥ 2 的交易
- 短中期仓回撤 4%/6%/8% 分级降风险、停新仓、暂停复核
```

## 研究边界

公开资料支持以下原则：

- 资产配置应由期限、风险承受能力和目标决定，而不是永远固定一个比例；
- 个股组合需要充分分散；
- 分批投入能降低部分择时压力，但长期拖延现金也有机会成本；
- 主动交易需要严格限制仓位与单笔风险；
- 入场前应定义退出和最大损失；
- 时间止损、Reward/Risk 和分批退出可作为短中期交易计划的一部分。

但 `70/30`、`80/20`、`85/15`、`40/30/30`、`4%/6%/8%` 等具体参数均是本仓库的治理基线，不宣称为学术研究证明的唯一最优值。后续必须用真实实盘数据继续校准。

## 两套系统之间的资金纪律

```text
长期资金靠时间、企业现金流和价值增长赚钱；
短中期资金靠可验证的交易优势赚钱；
两套系统不能互相为错误买单。
```

短中期仓盈利超过战略上限时，优先把已实现的超额利润转入长期养老仓或待配置现金池；短中期仓因亏损缩水时，不允许自动从长期仓抽钱补足。
