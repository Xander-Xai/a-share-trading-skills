# 资金分配与交易风控调研验证 — 2026-08-26

> 本文件记录 `shared/capital-allocation-and-entry-policy.md` v2.0 的公开资料验证过程与边界。
>
> 重要说明：公开研究可以验证“按风险承受能力和期限做资产配置、提高分散度、控制主动交易风险、预先定义仓位与退出、分批投入存在机会成本”等原则，但**没有权威研究证明 70/30、80/20、85/15 或 40/30/30 是唯一最优比例**。本仓库中的具体数字属于风险治理参数，应结合真实实盘结果持续校准。

## 1. 本轮结论

### 1.1 资金规模不能机械套用固定 70/30

本仓库采用动态 Size Cap：

| 股票专用资金规模 | 长期养老仓 | 短中期仓 |
|---:|---:|---:|
| ≤5 万元 | 70% | 30% |
| 5–30 万元 | 75% | 25% |
| 30–200 万元 | 80% | 20% |
| 200–1000 万元 | 85% | 15% |
| ≥1000 万元 | 85%–90% | 10%–15% |

但最终短中期占比使用：

```text
Short Allocation = min(Size Cap, Risk Cap, Edge Cap)
```

其中：

- `Size Cap`：由股票专用资金规模给出的治理上限；
- `Risk Cap`：由“允许短中期策略最多拖累总账户多少”反推；
- `Edge Cap`：由短中期策略的真实净收益、最大回撤、样本量和纪律执行决定。

因此，资金越大并不意味着必须同比例放大主动交易资金。核心财富/养老资金越大，资本保全与分散的重要性越高。

## 2. 资产配置与分散：公开资料支持什么

### Investor.gov — Asset Allocation and Diversification

https://www.investor.gov/introduction-investing/getting-started/asset-allocation

关键验证：

- 资产配置取决于时间期限和风险承受能力；
- 不存在适用于所有人的唯一固定配置；
- 应在资产类别之间以及同一资产类别内部进行分散；
- 当配置因市场涨跌偏离目标时，需要再平衡，但不必频繁操作。

这支持本仓库“不把固定 70/30 作为永久答案”和“使用漂移区间而非每天再平衡”的设计。

### Investor.gov — Beginners’ Guide to Asset Allocation, Diversification, and Rebalancing

https://www.investor.gov/additional-resources/general-resources/publications-research/info-sheets/beginners-guide-asset

关键验证：

- 组合需要同时跨资产与跨公司/行业分散；
- 只持有 4–5 只个股通常不足以形成充分分散；
- 时间期限和风险承受能力变化时，应重新评估资产配置。

因此，本仓库随着资本增长提高长期持股数量、降低单股上限，而不是永远只用 5 只长期股。

## 3. 长期建仓：为什么默认 3 批而不是无限分批

### Vanguard — Cost averaging: Invest now or temporarily hold your cash?

https://corporate.vanguard.com/content/dam/corp/research/pdf/cost_averaging_invest_now_or_temporarily_hold_your_cash.pdf

关键验证：

- 在其历史研究中，一次性投入相对分批投入约有三分之二时间表现更好；
- 研究中的三个月 Cost Averaging 框架说明，现金等待存在机会成本；
- 分批投入可以暂时降低风险，但不能被理解为“越慢买越安全”。

本仓库据此采用折中治理规则：

```text
长期单股默认：3 批 40% / 30% / 30%
通常完成窗口：约 1–3 个月
```

但这不是学术意义上的“最优比例”。若小资金受 100 股交易单位限制，可改 60/40；若单股金额大、流动性一般或事件不确定性高，可改 30/25/25/20。

## 4. 为什么限制短中期交易资金

### Barber & Odean — Trading Is Hazardous to Your Wealth

https://faculty.haas.berkeley.edu/odean/papers/returns/individual_investor_performance_final.pdf

关键验证：

- 样本为 66,465 个家庭账户；
- 交易最频繁的一组年收益显著落后市场；
- 研究核心结论是高换手和过度自信可能显著侵蚀个人投资者表现。

这不能推出“所有短中期交易都必然失败”，但支持本仓库的治理原则：

```text
主动交易仓必须用真实业绩挣仓位；
没有被验证的交易系统，不得成为核心财富账户的主风险来源。
```

## 5. 短中期仓位与单笔风险

### Charles Schwab — Elements of a Smart Trade Plan

https://www.schwab.com/learn/story/5-elements-smart-trade-plan

关键验证：

- 交易计划应在下单前确定单笔愿意承担的最大风险；
- Schwab 给出的常见交易者参考为单笔账户风险约 1%–2%；
- 仓位大小应由风险预算反推，而不是先买一个固定金额再决定止损。

本仓库因为短中期仓附属于长期养老系统，使用更保守的默认值：

```text
单笔最大风险：短中期仓净值 0.5%–1.0%
硬上限：1%
全部未平仓初始风险合计：≤3%
```

仓位公式：

```text
目标持仓金额 ≈ 单笔允许亏损金额 / 初始止损距离
```

## 6. 短中期退出：价格、逻辑和时间三种维度

### Fidelity — Exit Strategies

https://www.fidelity.com/learning-center/trading-investing/trading/exit-strategies

关键验证：

- 入场前就应该考虑退出条件；
- 可以使用基本面、技术、Profit/Loss Ratio 与 Time Exit 等不同退出框架；
- 2:1 或 3:1 的 Profit/Loss Ratio 是常见交易计划示例；
- Time Exit 适合处理价格长期横盘、走势太慢或未按预期发展的交易。

因此本仓库短中期策略使用：

```text
价格/失效止损
+
逻辑止损
+
时间止损
```

并优先选择潜在 Reward/Risk ≥ 2 的交易；达到约 +1.5R～+2R 后可分批兑现，再让剩余仓位跟随趋势。

## 7. 补仓原则

### 长期仓

价格下跌不是自动买入信号。只有以下四个 Gate 同时通过才允许补仓：

```text
Thesis Gate
Balance Gate
Valuation Gate
Portfolio Gate
```

即：投资逻辑、资产负债/现金流、估值安全边际、组合集中度同时通过。

### 短中期仓

禁止为降低持仓成本向亏损仓位机械加码。第二批/第三批只能是：

```text
第一笔判断得到正向确认
→ 在总风险预算仍合格时加仓
```

而不是：

```text
第一笔亏损
→ 越跌越买
```

## 8. 止损和止盈的长期/短中期分离

### 长期

不采用统一 -5%、-8%、-10% 的机械价格止损。

主要使用：

- 投资逻辑被证伪；
- 盈利能力结构性破坏；
- 分红削减且背后是现金流/偿债恶化；
- 审计/治理红旗；
- 债务或监管资本失控。

止盈也不采用“盈利 20% 自动卖出”，而由：

```text
估值过高
+
单股/风险簇超配
+
机会成本
```

触发 `TRIM`。

### 短中期

入场前先定义交易失效点，再反推仓位；不允许入场后把止损向更亏损方向放宽。

盈利管理采用 R 倍数和趋势退出，不用一个固定百分比覆盖所有交易。

## 9. 账户级熔断

本仓库当前内部治理线：

```text
短中期仓回撤 -4%
→ 单笔风险最高从 1% 降至 0.5%

回撤 -6%
→ 暂停新开仓，开始系统复盘

回撤 -8%
→ 暂停短中期策略，完成正式策略复核后再恢复
```

这些数字属于本仓库的**保守风险治理参数**，不是公开研究证明的唯一最优阈值。未来应根据真实实盘最大回撤、胜率、盈亏比、连续亏损分布进行校准。

## 10. 大资金需要增加流动性约束

当账户达到百万、千万级时，不能只按百分比放大订单，还要检查：

- 单股日均成交额；
- 买卖价差；
- 计划订单占日均成交金额比例；
- 是否存在涨跌停/低流动性风险；
- 是否需要限价和进一步拆单。

因此“1000 万账户长期 3 批”并不意味着每一批都用一个订单完成。**策略批次**和**交易执行拆单**是两个层级：前者管理投资判断，后者管理流动性和冲击成本。

## 11. 当前仓库政策边界

当前参数是 v2.0 初始治理基线，后续应按真实数据升级：

1. 记录所有短中期交易的 `R`、滑点、费用、MAE/MFE、持有天数；
2. 每季度计算胜率、平均盈亏比、Profit Factor、最大回撤、连续亏损长度；
3. 用滚动 6–12 个月数据重新评估 `Edge Cap`；
4. 若主动交易无正期望，短中期仓应下降，而不是通过增加仓位弥补；
5. 长期仓每年根据资产规模、风险承受能力和退休目标重新评估目标配置。

## 12. 结论

```text
资金越大，越不能把“固定比例 + 固定买入次数”机械放大。

长期仓：
资本保全、分散、估值、企业质量优先。

短中期仓：
风险预算、真实 Alpha、止损纪律、执行容量优先。

最终配比不是只看本金：
Short Allocation = min(Size Cap, Risk Cap, Edge Cap)
```
