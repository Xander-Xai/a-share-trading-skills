# A股长期 / 短中期资金分配、建仓与风险管理策略 v2.0

> 适用范围：本仓库内长期养老投资 Skill 与短中期交易 Skill 的共同顶层资金管理规则。
>
> 核心变化：不再把“70/30 + 固定分几次买”当成所有资金规模都适用的答案，而是改为 **资本规模 + 风险预算 + 策略有效性 + 流动性** 四层约束。
>
> 前提：本文讨论的是**专门可用于股票投资、能够承受波动的股票资金**。如果 10 万 / 100 万 / 1000 万代表的是全部可投资金融资产，而不是单独的股票资金，应先完成现金、固收、保险/保障、其他资产类别的一级资产配置，再把分配给 A 股股票系统的资金带入本规则。

---

## 1. 第一性原理

名义本金从 1 万变成 1000 万，不会让股票的百分比波动自动变大；但会改变四件事：

1. **绝对损失金额**：同样 -10%，1 万亏 1000 元，1000 万亏 100 万元。
2. **资本保全的重要性**：本金越大，继续“验证主动交易能力”所需要冒的相对风险越没有必要过高。
3. **分散能力**：资本越大，越有条件持有更多行业和风险簇，降低个股永久损失对总资产的冲击。
4. **执行与容量**：单笔资金越大，流动性、滑点、冲击成本和成交方式越重要。

因此不使用一个永久固定的 70/30，而使用：

```text
长期养老仓 = 财富复利与资本保全主引擎
短中期仓   = 有限风险预算下争取 Alpha 的卫星仓
```

短中期仓必须证明自己有资格占用更多资本，而不是随着本金增长同比例无限放大。

---

## 2. 资本规模对应的默认长期 / 短中期配比

以下是**股票专用资金**的默认治理基线，不是学术研究证明的唯一最优解。

| 股票专用资金规模 | 长期养老仓 | 短中期仓 | 解释 |
|---:|---:|---:|---|
| ≤ 5 万元 | 70% | 30% | 受 A 股最小交易单位影响，短中期过小会难以实际执行；但长期分散度也有限 |
| 5–30 万元 | 75% | 25% | 开始具备较好的长期分散能力，主动交易风险应下降 |
| 30–200 万元 | 80% | 20% | 长期资产成为明显主仓；主动策略只承担卫星收益任务 |
| 200–1000 万元 | 85% | 15% | 资本保全优先级明显提高；15% 已是相当可观的主动资金 |
| ≥ 1000 万元 | 85%–90% | 10%–15% | 若这部分资金承担核心财富/退休职责，优先 90/10；仅在交易系统长期验证后考虑靠近 85/15 |

### 用户举例

```text
10 万股票资金：  7.5 万长期 / 2.5 万短中期
100 万股票资金： 80 万长期 / 20 万短中期
1000 万股票资金：850–900 万长期 / 100–150 万短中期
```

### 为什么比例随资本规模变保守

不是因为“钱多了百分比风险变大”，而是因为：

```text
主动交易的容量与可验证 Alpha 有上限
而绝对损失金额随本金线性放大
```

Barber & Odean 对 66,465 个个人投资账户的经典研究发现，高换手组的长期结果显著落后于市场；深交所投教材料同样提示过度交易与业绩之间通常存在负向关系。因此，在主动策略尚未持续证明优势之前，不应让它成为核心财富账户的主导风险来源。

## 3. 配比不是只看本金：三重上限模型

最终短中期仓位不得只查上表，而应计算：

```text
Short Allocation
= min(
    Size Cap,       # 资本规模上限
    Risk Cap,       # 总账户允许被短中期拖累多少
    Edge Cap        # 交易系统真实业绩允许占多少
  )
```

### 3.1 Size Cap

使用第 2 节的资本规模表。

### 3.2 Risk Cap

定义：

```text
允许短中期系统对总股票账户造成的最大压力损失 = B
短中期策略压力情景最大回撤 = D

短中期仓上限 S <= B / D
```

例如：

```text
只愿意让短中期系统最多拖累总账户 5%
压力情景认为短中期仓可能回撤 25%

S <= 5% / 25% = 20%
```

所以即使资本规模表允许 25%，风险预算仍会把它降为 20%。

### 3.3 Edge Cap：用业绩挣仓位

短中期资金只能因为**经过验证的交易优势**增加，而不能因为“最近行情好”增加。

升级仓位前至少检查：

- 有足够真实交易样本；
- 覆盖上涨、震荡、下跌等不同环境；
- 扣除佣金、印花税和滑点后仍有正期望；
- 最大回撤受控；
- 收益不是由极少数幸运交易贡献；
- 止损、仓位、复盘纪律没有系统性破坏。

若没有充分验证，使用资本规模表的**保守端**，不得主动向上加杠杆式放大。

## 4. 长期仓：随着资本增长提高分散度

SEC/Investor.gov 的投资者教育材料强调，分散投资应同时发生在资产类别之间和资产类别内部，并指出只持有四五只个股通常不足以形成充分分散；个股组合需要更多经过选择、经济驱动不同的公司。

因此长期仓不是永远只持有 5 只股票。

| 股票资金规模 | 长期仓建议持股数量 | 单只长期股目标上限 | 单一风险簇参考上限 |
|---:|---:|---:|---:|
| ≤5 万 | 2–4 只或使用宽基/红利 ETF 补分散 | 30%（受最小交易单位制约） | 40% |
| 5–30 万 | 5–8 只 | 20% | 30%–35% |
| 30–200 万 | 8–12 只 | 15% | 25%–30% |
| ≥200 万 | 10–15 只 | 10%–12% | 20%–25% |

这些是治理上限，不代表必须为了凑数量买入低质量公司。没有合格标的时允许保留现金或使用高度分散的 ETF 作为过渡。

## 5. 长期仓的购入策略：默认 3 批，不因本金变大机械变成 10 批

Vanguard 关于 lump-sum 与 cost averaging 的研究显示，在其全球股票历史样本中，一次性投入相对三个月分批约 68% 的时间表现更好。研究含义不是“所有单股都应该一次满仓”，而是：**分批有风险控制价值，但把现金拖得过久也有机会成本。**

因此长期个股采用：

```text
标准模式：3 批 40% / 30% / 30%
建议完成窗口：通常 1–3 个月
```

### 5.1 何时改为 2 批

```text
60% / 40%
```

适用于：

- 小资金受 100 股交易单位限制；
- 公司高度成熟、流动性强；
- 当前估值安全边际非常明显；
- 目标单股仓位本来就较小。

### 5.2 何时改为 4 批

```text
30% / 25% / 25% / 20%
```

适用于：

- 单只目标仓位金额较大；
- 公司波动或事件不确定性较高；
- 财报/分红/行业催化将在未来数周继续释放信息；
- 流动性一般，需要控制成交冲击。

原则上**不因账户从 100 万增长到 1000 万就机械变成 5–10 批**。真正决定批次的是“单股目标金额 ÷ 流动性、信息不确定性、估值安全边际”。

### 5.3 长期每一批的触发逻辑

**第一批：建立底仓**

- 公司通过长期 Skill 硬性筛选；
- 当前估值进入 Max Buy Price / 可接受区间；
- 组合集中度未超限。

**第二批：价格或事实进一步有利**

满足至少一项：

- 价格更便宜，但基本面未坏；
- 财报/现金流/分红政策进一步验证原逻辑；
- 行业短期错杀但长期逻辑未改变。

**第三/第四批：强确认**

- 基本面仍通过；
- 估值仍有安全边际；
- 没有治理、现金流、分红、资产负债表红旗；
- 组合仍需要该风险暴露。

如果股价上涨导致估值超过最高买入价，后续批次自动取消，不为“买满计划”追高。

## 6. 长期补仓策略：价格下跌只是“复核触发器”，不是买入信号

长期补仓必须同时满足四个 Gate：

```text
Thesis Gate      投资逻辑仍成立
Balance Gate     资产负债/现金流或监管资本未恶化
Valuation Gate   当前估值更有安全边际
Portfolio Gate   单股和风险簇仓位仍未超限
```

四个 Gate 有一个不通过，就不补。

### 强制复核，而非自动补仓

- 从成本或近期关键价格下跌约 15%–20%：触发一次重新研究；
- 下跌约 25%–30%：必须做深度 thesis review，再决定 HOLD / ADD / TRIM / EXIT；
- 不允许使用“已经跌很多了”作为补仓理由。

以上百分比是仓库内部风险治理触发线，不宣称是市场统一最优止损线。

---

## 7. 长期止损：不用机械价格止损，用“投资逻辑止损”

长期养老股的风险来自**永久性价值损失**，而不是正常波动。因此长期仓默认不使用 5%、8%、10% 这样的机械价格止损。

### EXIT 触发

出现以下之一，重新评估后可直接退出：

- 商业模式或护城河发生结构性破坏；
- 正常化盈利能力永久下降；
- 分红削减背后是现金流、偿债或资本充足恶化；
- 重大审计、财务造假、治理、资金占用问题；
- 债务或资本结构明显失控；
- 原始投资逻辑被事实证伪。

### 为什么不把普通 stop-loss 直接套在长期仓

Investor.gov/SEC 对 stop order 的投资者公告提醒：止损触发价并不是保证成交价，短时波动也可能触发止损并以明显不同的价格成交。因此长期仓更适合把大幅价格变化作为“研究警报”，而不是自动把短期波动转化为永久卖出。

---

## 8. 长期止盈：不设“涨 20% 就卖”，使用估值 + 集中度 + 机会成本

长期优质企业上涨本身不是卖出理由。

### HOLD

- 投资逻辑成立；
- 估值合理；
- 仓位未超上限。

### TRIM

满足以下任一类条件可减仓：

1. 单股上涨后超过长期仓最大单股权重；
2. 单一风险簇明显超限；
3. 当前价格明显超过 Bull / Base Fair Value，未来 3–5 年隐含回报已显著下降；
4. 存在质量相近、但安全边际明显更高的替代品。

### EXIT

只有投资逻辑被破坏或风险不可接受时退出，不因为账面盈利达到固定百分比就全部卖掉。

---

## 9. 长期持仓与再平衡

### 9.1 复核频率

- 季度：轻复核经营、现金流、负债/资本、关键 KPI；
- 年报：完整重做评分、正常化盈利、分红压力测试和估值；
- 重大事件：立即复核。

### 9.2 再平衡

Vanguard 与 Investor.gov 都强调再平衡的目标是把风险暴露拉回战略配置，而不是预测下一轮赢家。

优先顺序：

```text
新增资金
→ 分红现金
→ 短中期已实现利润
→ 最后才卖长期优质持仓
```

不需要每天精确再平衡。使用阈值/区间再平衡。

---

## 10. 短中期仓：仓位必须按“最大可承受损失”计算，而不是拍脑袋买金额

Schwab 的交易计划教育举例提示，一些交易者把单笔账户风险限制在约 1%–2%；Fidelity 的 position sizing 材料强调不要让单笔最大风险超过账户的 2%，并明确写出不要向亏损仓位继续加码。

本仓库为了与养老主账户共存，使用更保守的规则：

```text
单笔风险预算：短中期仓净值的 0.5%–1.0%
硬上限：1.0%
全部未平仓交易的总初始风险：≤ 短中期仓净值的 3%
默认不使用融资杠杆
```

### 仓位公式

```text
单笔目标持仓金额
≈ 单笔允许亏损金额 / 初始止损距离
```

例如：

```text
短中期仓 20 万元
单笔风险预算 1% = 2000 元
技术止损距离 5%

目标持仓金额 ≈ 2000 / 5% = 4 万元
```

即该交易约占短中期仓 20%。

### 额外上限

- 单只短中期股票：原则上不超过短中期仓的 20%；
- 同一高度相关板块/风险簇：原则上不超过短中期仓的 40%；
- 同时持仓：通常 3–5 只；
- 任何情况下都要先满足“最大亏损预算”，再考虑满不满仓。

## 11. 短中期购入：默认 2 批 50/50

### 第一批 50%：Setup Entry

必须在下单前写清：

- 入场理由；
- 失效价格/条件；
- 初始止损；
- 计划持有时间；
- 至少一个合理的利润目标；
- 预期 Reward / Risk。

### 第二批 50%：Confirmation Entry

只有**走势证明第一笔越来越正确**才允许加入，例如：

- 突破后站稳；
- 回踩关键位后重新走强；
- 成交量/资金/催化继续确认；
- 新信息强化原始交易逻辑。

加入第二批后，必须重新计算总仓位与总风险，确保仍不超过 1% 单笔风险预算。

### 禁止

```text
第一笔亏损
→ 为了摊低成本买第二笔
```

Fidelity 的 position-sizing 教育材料明确提示不要向亏损仓位不断加码以期待回到盈亏平衡。

### 三批例外

资金更大、策略本身存在三个清晰确认层级时，可使用：

```text
50% / 30% / 20%
```

但第 2、3 批仍必须是**正向确认加仓**，不是向下摊薄成本。

---

## 12. 短中期止损：先定失效点，再反推仓位

不使用“所有股票统一亏 5% 就卖”的机械方案。

执行顺序：

```text
先确定交易逻辑失效点
→ 得到止损距离
→ 用风险预算反推可买金额
→ 如果仓位过小或 Reward/Risk 不合理，跳过交易
```

### 硬规则

- 入场前必须有止损/失效条件；
- 入场后禁止把止损向更亏损方向放宽；
- 出现跳空时，实际成交价可能明显差于触发价；止损不能被当成“保证损失上限”的保险；
- 若交易逻辑失效，先退出，不把短中期仓改名为长期仓。

Investor.gov/SEC 明确提醒 stop order 的 stop price 只是触发价，不保证最终执行价，极端波动或跳空可能造成明显滑点。

---

## 13. 短中期止盈：以 R 倍数 + 趋势退出替代固定百分比

Fidelity 的交易教育材料将 2:1、3:1 profit/loss ratio 作为常见的计划示例。本仓库因此使用下面的默认框架：

### 入场前

优先选择：

```text
预期潜在收益 / 初始风险 >= 2
```

若明显达不到 2R，则降低优先级或放弃交易。

### 持仓后

- 到达约 +1.5R～+2R：可分批兑现 1/3～1/2；
- 剩余仓位：根据趋势结构、关键均线/支撑、移动止盈或 trailing 思路管理；
- 盈利扩大后可以上移保护线，但不把保护线向下放宽；
- 若原计划是均值回归/事件交易，应在预设目标附近退出，不强行改造成趋势长持。

Schwab 也建议在高波动交易环境中可考虑先兑现部分利润、让剩余仓位继续参与，并可使用 trailing stop 管理后续退出。但 trailing/stop 仍存在跳空和成交价不确定风险。

---

## 14. 短中期时间止损

短中期交易不只存在价格止损，也存在“时间成本”。

如果策略定义的是 5–15 个交易日机会：

- 到计划时间仍未出现预期走势：至少重新评估；
- 资金长期横盘占用且没有新的逻辑增强：降低仓位或退出；
- 不允许因为“还没亏到止损价”就无限延期。

Fidelity 的 exit strategy 教育材料也把 time exit 作为常见退出框架之一。

---

## 15. 短中期账户回撤熔断

以下阈值是本仓库的**保守治理规则**，不是学术研究声称的唯一最优值：

```text
短中期仓从权益高点回撤 4%
→ 单笔风险从最高 1% 降到最高 0.5%
→ 暂停提高仓位

回撤 6%
→ 停止新开仓
→ 只管理已有仓位
→ 复盘最近交易与市场环境

回撤 8%
→ 暂停短中期策略
→ 不从长期养老仓抽钱补血
→ 完成正式策略复核后再恢复
```

核心原则：

```text
亏损时缩小风险预算
而不是加大下注试图快速回本
```

## 16. 长期 / 短中期之间的再平衡与利润回流

目标比例根据资本规模动态确定，不再永久固定 70/30。

每个目标允许约 ±5 个百分点的漂移区间；超过区间才考虑再平衡。

### 短中期赚钱

若主动仓因为盈利超过上限：

```text
超额已实现利润
→ 优先转入长期养老仓 / 待配置现金池
```

目的是把短期 Alpha 转化为永久长期资产。

### 短中期亏损

若短中期仓因亏损低于目标：

```text
禁止自动从长期仓提款补回目标比例
```

先完成策略复核。只有确认策略仍有效后，才使用**未来新增资金**逐步补足。

---

## 17. 大资金执行：流动性优先级上升

当账户达到百万、千万级时，必须额外检查：

- 单股日均成交额；
- 买卖价差；
- 计划订单占日均成交金额比例；
- 是否属于小市值/低流动性/连续涨跌停风险标的；
- 是否需要把单次订单进一步拆分。

Investor.gov 对 market order 的说明强调：市场单不保证执行价格，大订单也可能在不同价格成交。因此随着单笔金额上升，应更加重视限价、分单和流动性，而不是一次性用市价单追价。

对于 1000 万股票账户，本仓库默认长期仓应主要使用高流动性标的；短中期策略如果依赖低流动性小票，应主动降低仓位上限，而不是只按账户比例放大金额。

## 18. 一张总表

| 模块 | 长期养老 | 短中期 |
|---|---|---|
| 角色 | 财富复利 / 资本保全主引擎 | Alpha 卫星仓 |
| 资金占比 | 随资本从 70% 提升到 85%–90% | 随资本从 30% 降到 10%–15% |
| 默认建仓 | 3批 40/30/30 | 2批 50/50 |
| 大资金建仓 | 必要时4批 30/25/25/20 | 仍以1–2批为主，最多3批确认式加仓 |
| 补仓 | 基本面+估值+组合同时通过才加 | 不向亏损仓位补仓 |
| 止损 | 投资逻辑止损，不机械价格止损 | 失效点止损，先定风险再算仓位 |
| 止盈 | 估值/集中度/机会成本触发 TRIM | 约2R目标 + 分批止盈 + 趋势退出 |
| 单股风险 | 大资金长期单股上限逐步降至10%–12% | 单笔最大损失≤短中期仓1% |
| 组合熔断 | 事件驱动深度复核 | 4%/6%/8% 回撤分级降风险/暂停 |
| 利润处理 | 分红进入组合级再配置 | 超额利润逐步回流长期仓 |

## 20. 最终原则

```text
资金越大，不是交易次数越多、单笔越大；
而是越应该把“资本保全”放到优先级更高的位置。

长期仓靠企业价值、现金流、分红与时间复利；
短中期仓靠可验证 Alpha，但必须被严格风险预算约束。

长期下跌先研究，不机械补；
短中期亏损不补仓，信号失效就退出；
短中期赚到的钱，逐步变成长期资产。
```
